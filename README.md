# kurtisnotcurtis Scoop Bucket

[![Tests](https://github.com/kurtisnotcurtis/scoop-bucket/actions/workflows/ci.yml/badge.svg)](https://github.com/kurtisnotcurtis/scoop-bucket/actions/workflows/ci.yml) [![Excavator](https://github.com/kurtisnotcurtis/scoop-bucket/actions/workflows/excavator.yml/badge.svg)](https://github.com/kurtisnotcurtis/scoop-bucket/actions/workflows/excavator.yml)

Personal [Scoop](https://scoop.sh) bucket for packages by **kurtisnotcurtis**.

## Installation

```powershell
scoop bucket add kurtisnotcurtis https://github.com/kurtisnotcurtis/scoop-bucket
scoop install kurtisnotcurtis/shieldsheriff
```

## Included Apps

- **shieldsheriff** — Simple, nag-free control for Windows 11 Defender ([repository](https://github.com/kurtisnotcurtis/shieldsheriff))
